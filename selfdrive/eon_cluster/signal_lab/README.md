# 한국형 신호등 · 메인폰 연동 (관찰 모드)

EON의 전방 영상을 메인폰의 한국 신호등 모델로 분석하고, 인식 후보를 EON 및 S20 HUD에 표시합니다. 기존 네이버 신호정보와 구별되는 **AI 후보**이며 내 진행 신호로 확정하거나 차량 제어에 사용하지 않습니다.

## 사용

1. EON에서 `g_blinker`를 업데이트하고 인게이지 해제 상태에서 openpilot을 재시작합니다. `signal_lab` 서버가 EON에서 자동으로 시작합니다. 수동 서버 설치는 필요하지 않습니다.
2. 이온웹 **주행 → 메인폰 신호등 AI 연결**에서 **4자리 연결 코드**와 EON IP를 확인합니다. `0123`처럼 앞자리 0도 포함합니다. 기존 32자리 파일은 처음 시작할 때 4자리로 전환하며 이후 재부팅해도 유지합니다.
3. `signal-lab-auto` 릴리스의 `EonSignalLab-Korea-latest.apk`를 메인폰에 설치합니다. 이전 0.1과 같은 시험 서명이며 앱 패키지도 `ai.comma.signallab`으로 같습니다.
4. 메인폰 앱에 **EON_IP:7799**와 **4자리 숫자 코드**를 입력하고 인식 시작을 누릅니다. EON 카메라가 동작해야 합니다. 메인폰 카메라를 사용하지 않습니다.
5. EON의 수신 결과 페이지와 메인폰에서 검출 박스를 확인할 수 있습니다. S20 HUD는 기존 `remote-hud-auto`의 최신 APK로 업데이트하면 `AI 후보`가 표시됩니다.

메인폰과 EON은 같은 로컬 네트워크에 연결합니다. 기존처럼 메인폰 핫스팟에 EON이 접속한 구성입니다. 잘못된 코드를 같은 주소에서 5회 입력하면 30초 동안 재시도를 제한합니다. 앱은 한 번에 최대 10분 동안 시험하며 중지/재시작할 수 있습니다.

## 처리 범위

- EON: RGB 전방 프레임 상단 70%, 최대 폭 1280, JPEG 85, 요청 상한 약 5fps. 폰의 요청이 없으면 카메라를 구독하지 않습니다.
- 메인폰: 한국 `original-korean-traffic-light` 및 제작자의 추가 사례로 학습된 LightSignal v20260727. 빨강·노랑·초록·좌회전 클래스를 처리하며 속도 표지판은 제외합니다.
- 서버: 프레임/세션/모델 SHA-256 확인, 850ms를 넘은 결과 및 재전송·역순 결과 폐기. 1.2초 이상 오래된 후보는 HUD에서 숨깁니다.
- 결과: `/dev/shm/eon_signal_lab.json`. 기존 내비 신호 파일·조향·가속·브레이크 메시지를 변경하지 않습니다. 선택 프로세스가 중단돼도 인게이지 오류로 취급하지 않습니다.

한국형 모델 카드에 박스 위치·반전 증강에 따른 화살표 학습 문제와 야간·역광·먼 신호등의 한계가 기재돼 있습니다. 국내 도로에서 기존 모델보다 나은지는 아직 비교 검증하지 않았습니다. 폰·EON 실기기 연결과 실제 처리 지연은 기기에서 확인해야 합니다.

## 개발

서버는 표준 라이브러리로 시작하며 VisionIPC/Pillow는 프레임을 요청할 때만 로드합니다. 연결 코드는 `/data/eon_signal_lab/token`에 권한 0600으로 저장합니다. 이온웹의 기존 인증을 거쳐 코드를 조회합니다. 현재 4자리 코드를 임의로 바꾸려면 서비스가 꺼진 상태에서 그 파일을 변경해야 하며 숫자 4자리만 허용합니다.

```sh
python3 -m unittest discover -s selfdrive/eon_cluster/signal_lab/tests -v
python3 selfdrive/eon_cluster/android_signal_lab/build_apk.py
```

## 중앙 후보 안정화 (0.3)

서버는 원본 검출을 보존하고 별도 `selection`만 폰·수신 페이지·HUD에 강조합니다.
회색 박스는 원본, 색상 박스는 연속 확인된 중앙 후보입니다. 중앙 위치는 내 차로와의 대응을 증명하지 않습니다.

- 원본 상단 70% 카메라 영상의 정규화 좌표에서 중심 x=0.2~0.8, y=0.08~0.72만 선택 대상으로 삼습니다. 차량등이 들어오기 쉬운 아래 영역과 큰 박스를 제외하며, 실제 신호가 낮게 보일 때도 미검출될 수 있습니다.
- 겹치는 박스는 신호기 후보로 묶고 같은 클래스의 중복을 제거합니다. 빨강+좌회전은 구분해서 유지합니다.
- 가장 중앙인 후보를 사용하되 두 후보의 중앙 근접도가 0.04 미만 차이면 선택하지 않습니다. 중앙의 다른 차로 신호까지 구분하는 방식은 아닙니다.
- 같은 위치·색의 서로 다른 수신 프레임이 3회 이상, 0.6초 이상 이어져야 강조합니다. 신뢰도 문턱은 35%를 유지하며, 시간 확인을 거쳐도 표시 신뢰도 자체를 높이지 않습니다.
- 색 변화·색 충돌·위치 변경·검출 누락 시 기존 색을 즉시 지웁니다. 수신 간격이 0.65초를 넘으면 다시 확인합니다. 기존 850ms 결과 제한과 1.2초 HUD 만료도 유지합니다.
- 이 확인 과정은 최초 표시와 색 전환에 최소 0.6초를 추가합니다. 소수 프레임을 메우려고 이전 색을 유지하지 않으므로 미확정 표시가 늘 수 있습니다.
- 앱·EON을 함께 업데이트해야 합니다. 구버전 서버에 연결한 새 앱은 원본을 회색으로 표시하고 EON 업데이트를 안내합니다. 4자리 코드와 서명은 유지합니다.

이는 표시 안정화용 휴리스틱입니다. 차로 대응·정지선 거리 추정·자동 제동·자동 출발은 구현하지 않습니다. 보내주신 영상에서 관찰된 다중 후보/색 전환을 본뜬 단위 테스트를 포함하며, 개선 APK로 그 영상을 재추론하거나 실차에서 검증한 결과는 아닙니다.

# EON 블루투스 리모컨 (bt_remote)

클래식 블루투스 HID 리모컨을 EON에 직접 페어링해 크루즈 버튼과 차로변경 요청을 보냅니다.
폰 중계나 Wi-Fi를 거치지 않고, 별도 Android 앱도 쓰지 않습니다. 깜빡이 램프는 켜지지 않습니다
(제네시스 DH는 CAN에 깜빡이 명령 메시지가 없음).

## 리모컨 조건
- 클래식 블루투스(BR/EDR, "Bluetooth 3.0") HID. BLE 전용 리모컨은 Android 6(EON)에서 입력 장치가 생기지 않습니다.
- 예: 8BitDo Micro 키보드 모드. 게임패드 모드의 십자키(hat)·스틱도 읽지만 키보드 모드를 권장합니다.

## 설정 순서
1. 설정 → 커뮤니티 → `BLUETOOTH REMOTE` 켜기 (EON 블루투스가 켜지고 재부팅 후에도 유지).
2. 시동을 끄고 `리모컨 페어링 (Bluetooth 설정)` → OPEN → 리모컨을 페어링 모드로 두고 목록에서 선택.
   설정 화면은 3분 뒤 자동으로 닫힙니다. Android BACK은 누르지 마세요.
3. `리모컨 버튼 설정` → 기능과 누르기 방식(짧게/길게/두 번)을 고르고 LEARN → 리모컨 버튼을 누름.
   처음 학습한 리모컨만 이후 명령을 보낼 수 있습니다. P단 정차 중이나 시동을 끈 상태에서만 학습됩니다.

## 동작
- 크루즈 버튼(RES/SET/GAP/취소, RES·SET 길게)은 핸들 버튼과 같은 이벤트로 들어가며, 기어·페달 판단도 핸들 버튼과 같습니다.
- 차로변경 요청은 D단, 브레이크·가속페달을 밟지 않았을 때만 받습니다. 한 번 누르면 차로변경이 끝날 때까지 유지되고,
  3초 안에 시작하지 못하면(사각지대, 도로 끝, 속도) 취소됩니다. 브레이크나 반대 방향 핸들 조작으로도 해제됩니다.
- 명령은 0.4초 안에 처리되지 않으면 버려집니다. 늦게 도착한 입력이 나중에 실행되지 않습니다.

## 절전과 깨우기
- 리모컨은 오래 안 쓰면 스스로 연결을 끊습니다(펌웨어 동작, 설정 불가).
- 다시 연결된 뒤 1초 안의 입력은 "깨우기"로 보고 버립니다. 오래 쉬었다면 한 번 눌러 깨운 뒤 원하는 버튼을 누르세요.
- S9 HUD 표시: 초록 `리모컨 연결됨`, 주황 `절전 · 눌러 깨우기`(60초 넘게 안 누른 뒤 끊김),
  빨강 `리모컨 연결 끊김`(최근에 누른 뒤 끊김 = 비정상), 회색 `리모컨 연결 안 됨`.
  명령이 들어오면 1.5초 동안 명령 이름과 결과(EON 수신 / 차단 · 이유)를 보여 줍니다.

## 기록
- `/data/media/0/bt_remote.log`: 연결, 끊김(절전/LOST, 마지막 입력 후 시간), 깨우기로 버린 입력, 명령별 결과와 지연.
- `리모컨 버튼 설정` 화면 아래에 연결 횟수, 절전·비정상 끊김 횟수, 지연 평균·최대가 표시됩니다.
- 지연은 EON 커널이 입력을 받은 시점부터 명령을 적용한 시점까지입니다. 리모컨 안의 무선 구간은 잴 수 없습니다.

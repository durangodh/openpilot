# EON 웹 (g_web)

EON과 S20을 같은 Wi-Fi 또는 핫스팟에 연결합니다. EON이 부팅된 뒤
S20 Chrome에서 `http://EON-IP:7000`을 엽니다. 사용자 이름은 `eon`입니다.
처음 부팅하면 웹 프로세스가 암호를 생성합니다. EON SSH에서 아래 명령으로 확인합니다.

```sh
cat /persist/comma/eon-web-password
```

- **주행**에서 EON의 온로드 상태, CPU 온도와 남은 저장 공간을 확인합니다. **주행 비전 시작**을 누르면 기존 전방 카메라를 최대 480px·3fps로 미리 봅니다. 다른 탭으로 이동하면 중지합니다.
- **설정**에서 `selfdrive/apilot.json`에 정의되고 EON에 등록된 사용자 설정을 그룹별로 확인합니다. 이름과 설명으로 검색하고 JSON으로 백업할 수 있습니다. **변경** 버튼이 있는 항목은 시동을 끈 오프로드 상태에서 카탈로그의 정수 범위 내로 변경할 수 있습니다.
- **도구 → Git Commands**에서 현재 커밋과 최근 커밋을 확인하거나 `git pull`을 실행합니다.
  `git pull`은 시동을 끈 상태에서 `origin/g_web`의 커밋을 fast-forward 방식으로만 적용합니다.
  새 코드 적용은 다음 재부팅 때 이루어집니다. **브랜치 변경**은 로컬 또는
  이미 받아 둔 origin 브랜치에서 선택합니다. 로컬 추적 파일이 수정돼 있으면
  전환을 중단합니다. 대상 브랜치에 EON 웹이 없으면 재부팅 후 SSH로 접속합니다.
- **로그 → 대시캠**에서 완료된 최근 120개 구간을 주행별로 보고 rlog.bz2와 qlog.bz2를 내려받습니다. **리플레이**에서 속도, 앞차 속도, 차간 거리, 요청·실제 가속도를 재생합니다. 구간에 저장 영상이 있으면 브라우저에서 함께 재생합니다.
- **도구 → User / System**에서 tmux 출력 확인, **재부팅**, **재부팅하여 전체 재빌드**를 실행합니다.
  Git Pull·브랜치 변경·재부팅·재빌드는 시동이 꺼진 상태 또는 USB에 판다가 없다고 확인된 오프로드 상태에서 실행할 수 있습니다.
  전체 재빌드는 g_web 부팅 중 SCons 빌드 산출물을 정리한 뒤 다시 빌드합니다.
웹 접속은 신뢰할 수 있는 로컬 네트워크에서 사용하세요. HTTP 인증 정보는
전송 중 암호화되지 않으므로 포트 포워딩이나 공개 Wi-Fi에서 사용하지 마세요.

## 웹에서 주행 기록 설정

**설정 → 주행 기록**에서 **주행 로거**와 **리플레이용 전방 영상 녹화**를
각각 켜거나 끌 수 있습니다. 주행 중에도 설정이 반영됩니다. 로거를 끄면
현재 파일을 마무리하고, 다시 켜면 새 주행 기록이 시작됩니다. 전방 영상
옵션을 바꾸면 로거가 현재 파일을 닫고 새 구간으로 재시작하므로 짧은 기록
공백이 생깁니다. 영상은 주행 로거가 켜져 있을 때만 작동합니다.

## SSH에서 주행 로그 활성화

로거를 지원하도록 커널 조정이 끝난 EON에서 오프로드 상태에서 아래 명령을 실행합니다.

```sh
touch /persist/comma/enable-eon-route-logging
```

매니저는 실행 중에도 이 파일을 확인합니다. 로거와 기존 디스크 정리 프로세스를
함께 켜며, 디스크 여유가 부족해지면 오래된 로그가 정리됩니다. 주행을 마치고
새 로그 구간이 웹 화면에 나타나는지 확인합니다. 옵션을 끄려면 오프로드 상태에서 파일을 지웁니다.

## 리플레이용 전방 영상 기록

데이터 로그와 함께 브라우저용 저해상도 H.264 영상을 저장하려면 EON에 아래
옵션을 오프로드 상태에서 추가합니다. 주행 로그 옵션도 활성화되어 있어야 합니다.

```sh
touch /persist/comma/enable-eon-web-video
```

이후 기록되는 구간에 qcamera.mp4가 생깁니다. 영상 기록 중에는 EON의 하드웨어
인코더와 저장장치 부하가 추가됩니다. 영상 기록만 끄려면 오프로드 상태에서 위 파일을 지웁니다. 기존 데이터 로그는 데이터 리플레이로 열 수 있습니다.

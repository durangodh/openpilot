# EON 직접 Bluetooth 리모컨

이 방식은 R1을 **EON에 직접 BLE 연결**합니다. Android가 HID 입력 장치를
만들지 않아도 BLE 알림에서 버튼을 읽습니다. 버튼 명령은 EON 내부 명령 파일로
이동하며 S9와 Wi-Fi를 거치지 않습니다. S9 HUD의
화면·지도 데이터는 기존 UDP/TCP Wi-Fi 연결을 계속 사용합니다.

## R1 조이스틱형 리모컨 설정

제공된 R1 설명서에는 Android 마우스 모드(M+D)의 A/Enter, B/Back,
C/D 볼륨 버튼과 Android 게임 모드(M+B)의 방향 입력이 표시되어 있습니다.
실제 EON의 Linux 입력 코드는 페어링 상태와 모드에 따라 달라질 수 있으므로
코드에 버튼 번호를 고정하지 않았습니다. **Android 게임 모드**에서 방향키가
학습되는지 먼저 확인하세요. 키·D-pad hat·게임패드 아날로그 축을 학습할 수
있습니다. 포인터로 표시되는 마우스·터치 노드와 상대 커서 이동(`EV_REL`)은
차량 명령으로 변환하지 않습니다. 버튼이 학습되지 않으면 마우스 모드에서 C/D·A 등의 버튼을
시험할 수 있습니다.

1. 차량을 세우고 EON의 **Bluetooth 설정 / R1 페어링 해제**로 Android 설정을
   엽니다. `Paired devices`에 Magicsee R1이 있으면 톱니바퀴에서 `FORGET`을
   선택합니다. BLE 직접 연결은 Android 페어링이 없는 상태에서 동작합니다.
   Android의 **BACK**은 NEOS 설치 화면을 드러낼 수 있으므로 누르지 마세요.
   설정 화면은 3분 후 자동으로 닫힙니다.
2. R1 전원을 껐다 켜고 **M+B**를 함께 눌러 게임 모드로 전환합니다.
   LED가 깜빡이는 동안 EON의 **EON 리모컨 버튼 설정**으로 진행합니다.
3. EON 설정 → **EON 리모컨 버튼 설정**에서 동작과 짧게/길게/두 번 누르기를
   선택하고 `LEARN`을 누릅니다. 15초 안에 리모컨 버튼을 누릅니다.
4. 필요한 버튼을 학습한 뒤 **EON DIRECT REMOTE**를 켭니다.
5. S9 HUD 앱의 **S9 무선 리모컨 설정 (기존 방식)**에서 `리모컨 조작 사용`을
   끄고 S9와 리모컨의 Bluetooth 페어링을 해제합니다. S9의 기존 버튼 배정은
   EON에 복사되지 않습니다.

처음 학습한 BLE MAC 주소 또는 Bluetooth HID 장치의 고유 식별자만 차량 명령을 보낼 수 있습니다.
장치를 바꾸려면 설정 창의 **기기와 버튼 배정 초기화**를 눌러 다시 학습합니다.
직접 모드가 켜진 동안 S9에서 오는 원격
명령은 EON에서 거부됩니다. 명령을 쓰는 프로세스는 하나만 활성화됩니다.
설정은 기본적으로 꺼져 있고 버튼은 자동 배정되지 않습니다.
EON의 Android Bluetooth 전원 상태는 부팅 시 강제로 끄지 않으므로,
페어링 전에 켠 Bluetooth가 재부팅 후에도 유지됩니다.

BLE 방식은 EON에 설치되는 `ai.comma.eonbleremote` Android 서비스가 R1의
표준 HID BLE 서비스(`0x1812`) 보고서 알림(`0x2a4d`)을 읽습니다. 이 서비스는
로컬 루프백에 인증된 입력 상태만 전달하며, 리모컨 MAC은 첫 버튼 학습 때 고정합니다.
Android의 R1 페어링 기록이 있으면 BLE 연결이 차단될 수 있습니다. Android의
BLE 검색에 필요한 위치 권한은 EON 프로세스가 앱에 부여합니다. EON OS가 BLE
스캔 자체를 지원하지 않거나 R1에서 보고서 알림이 오지 않으면 직접 제어는
활성화되지 않습니다.

기존 HID 입력 방식은 보조 경로로 남아 있습니다. 입력 장치 탐색은 `/sys/class/input/event*/device/id/bustype=0005`와
`/dev/input/event*`를 사용합니다. 장치 고유 식별자(`uniq` 또는 `phys`)가
없으면 다른 같은 모델의 리모컨과 구분할 수 없어 입력을 사용하지 않습니다.
EON OS에서 Bluetooth HID 노드가 생성되고
openpilot 프로세스가 읽기·독점 권한을 가져야 합니다. 그렇지 않으면 설정을
켜도 명령은 전달되지 않습니다. 실제 EON, R1 리모컨 및 차량에서 동작을
확인하기 전에는 주행 중 사용하지 마세요.

학습이 되지 않으면 LEARN 창의 마지막 상태를 확인하세요. `BLE: R1 BLE 신호 없음`은
R1의 전원·M+B 모드 또는 Android 페어링 잔존을 확인해야 합니다.
`BLE 앱 미설치`는 BLE APK가 EON에 설치되지 않았다는 뜻입니다.
`인식 가능한 Bluetooth 입력 장치 없음`에는
EON의 전체 입력 노드 수, Bluetooth HID 노드 수, 고유 ID가 없는 노드 수와 R1 후보가 표시됩니다.
페어링만 되었고 실제로 연결되지 않았는지, 연결된 장치가 필터에서 제외됐는지 구분할 수 있습니다.
`입력 장치 열기 실패`·`입력 장치 독점 실패`는 EON의 입력 장치 권한을 확인해야 합니다.
`입력 감지`가 보이는데 학습되지 않으면 누르기 방식과 선택된 장치를 확인하세요.

# g_blinker NOO: carrot-rust 호환 이식

비교 원본: `ajouatom/openpilot`의 `bin9208/carrot-rust-dev`,
`c18326a46f1949ed2422c609987b7f75774843e5`.

## 반영한 동작

- `46a4f976`의 회전차로 대기: 현재 좌·우회전 준비 구간에서 정차 중에도
  `preLaneChange`를 유지한다. 분기, 유턴, 다음 회전, 리모컨, 레버에는 저속 예외를 적용하지 않는다.
- 일반 `NooLaneChangeSpeed` 미만에서는 10km/h 이상, 카메라의 실제 옆 차로,
  기존 경로 차로 선택·연속 여유 확인·도로경계·BSD 조건을 모두 만족해야 시작한다.
  왼쪽은 원본의 `atc_manual`처럼 운전자의 같은 방향 조향토크가 필요하다.
  `NooLaneChangeDelay` 동안 신호를 준비한 뒤 시작한다.
- 준비 거리는 기존 원본 이식값인 도로제한 30/50/100km/h에 따른 160/200/350m다.
  회전 시작 경계는 다음 도로 폭 5/10m에 따른 43/60m이며,
  폭을 제공하지 않는 내비의 기존 속도 기반 45~60m 처리는 유지한다.
- 실제 차로변경 허가와 준비 의도를 분리했다. 옆 차로가 아직 없거나 경로상
  차로 선택을 확인하지 못하면 대기만 하며, 차로변경 desire를 만들지 않는다.
  원래 차로 선택과 한 차로씩 이동 후 카메라 재확인 절차를 유지한다.
- GPS 신뢰도를 잃으면 이미 래치된 회전 desire도 즉시 해제한다.
  무한대·NaN 거리, 좌표 범위 오류도 유효한 안내/위치로 취급하지 않는다.
- `DhBcanBlinker`와 `DhBcanBlinkerHold`가 켜진 DH/ESP32 구성에서는 NOO 차로 준비와
  실제 회전에 기존 `HL/HR/KL/KR/C` 유지 프로토콜을 사용한다. 정차 대기가 길어도
  원터치 횟수를 소진해서 소등되는 문제를 줄인다. 기존 180초 상한과 ESP32의
  keepalive 종료 처리를 사용하며 운전자 리모컨이 우선한다. 전송 거절·취소 뒤
  같은 요청을 무한 재시도하지 않는다. 유지가 꺼져 있으면 기존 제한된 원터치를 사용한다.
- 이온웹 → 주행 → **내비 경로 미리보기**: 현재/다음 안내와 차량 앞쪽 경로를
  표시한다. 펼친 화면에서만 초당 한 번 요청하며 경로·위치·안내가 오래되면
  지도 대신 사유를 표시한다. 추가 지도 서버·타일 다운로드·상시 렌더링은 없다.

## 설정

`NooTurnPocket`: 기본 1(켬). EON 설정과 이온웹의 커브내비 설정에서 변경한다.
끄면 기존 `NooLaneChangeSpeed`를 그대로 사용한다.
`NavigationOnOpenpilot`와 차로 준비를 포함하는 `NooMode=0/2`, 차선변경 켜짐,
`LaneChangeNeedTorque >= 0` 조건이 필요하다. 회전조향은 기존처럼 `NooMode=0/1`이다.
기존 NOO 켜짐 여부나 저장된 모드·속도 설정을 강제로 바꾸지 않는다.

## N16과의 차이

EON의 `supercombo.dlc`/구형 `modeld`에는 `navigation[47]`와 `nav_map[1,1,256,256]`
입력이 없다. 이 변경은 현재 모델의 회전/차선변경 desire와 DH 깜박이 출력을
원본에 맞추는 이식이다. **N16이 경로 지도를 보고 주행 경로를 생성하는 NOO는 구현하지 않았다.**
웹의 경로 미리보기도 모델 입력이 아니다. N16을 쓰려면 외부 추론 장치/Jetlink,
모델 전처리·상태·출력 변환, 지도 타일 렌더러를 포함하는 모델 실행부 이식이 별도로 필요하다.
Mapbox 목적지 검색·자체 길찾기는 추가하지 않았으며 기존 내비 앱의 경로를 사용한다.

이후 추가한 [EON ↔ S20 N16 연결·속도 시험](noo-eon-n16-benchmark.md)은 이온웹에서
실행하는 성능 확인 단계다. N16 통신·추론 응답을 확인하지만 외부 결과를 주행 제어에 적용하지 않는다.

실차 부팅·조향·ESP32 점등 확인은 아직 수행하지 않았다. BSD와 카메라 차로 확인은
후방 접근 차량의 안전 간격을 보증하지 않으며 운전자의 감독과 개입이 필요하다.

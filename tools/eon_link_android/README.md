# 이온링크 0.2.0

Snapdragon 폰에서 N16을 계산하고, EON에서 선택한 모델 결과를 사용하는 실험용 앱이다.
**실제 주행 모델 발행 경로가 연결되어 있다.** 기본값은 기존 이온 모델이며, 외부
N16을 선택하면 정상 결과가 실제 `modelV2`를 통해 기존 조향·가감속 계획에 들어간다.
EON 단일 카메라를 N16의 두 영상 입력으로 사용하는 호환성은 실차 검증 전이다.

## 설치·모델 선택

1. `durangodh/openpilot`의 `g_blinker`를 업데이트하고 재빌드한다. C++ modeld 변경을
   포함하므로 웹 새로고침만으로 적용되지 않는다.
2. [이온링크 APK](https://github.com/durangodh/openpilot/releases/download/eon-link-android/EON-Link.apk)를
   설치한다. 패키지는 `ai.comma.eonlink`이다. 0.1.0 위에 업데이트하면 받은 모델을 유지한다.
3. 기존 Jetlink를 종료하고, EON과 폰을 같은 핫스팟에 연결한다.
4. 이온링크에서 **연결 시작 → N16 다운로드 → N16 준비 / 사용**을 누른다.
5. 이온웹 **주행 → 주행 모델 · 이온링크**에서 모델을 선택한다.
   - **기존 이온 모델**: 폰 없이 기존 방식으로 동작한다. 언제든 선택할 수 있다.
   - **외부 N16 · 실험용**: 인게이지 해제 상태에서 요청할 수 있다. D단·이동 중에도 선택할 수 있다.
6. IP는 비우면 UDP 자동 검색한다. 핫스팟이 브로드캐스트를 막으면 앱에 표시된 폰
   IP를 입력한다. 기본 포트는 **5600**이다. 설정은 EON에 저장된다.
7. 화면의 **실제 적용**을 확인한다. 연결 성공이나 외부 선택 요청만으로 외부 적용을
   표시하지 않는다. C++ modeld가 실제 발행한 상태를 표시한다.

차량 이동 중 화면 설정·시험 조작은 하지 않는다. 자동 검색은 같은 핫스팟 안의
주소 검색이며, 인터넷 통신이나 중간 핫스팟 자체를 제거하는 기능은 아니다.

## 발행과 복귀

- `eonlinkd`는 EON에서 시동 중 관리되는 별도 프로세스다. 최신 영상만 전송하고,
  검증된 후보를 공유 파일에 기록한다. 네트워크 작업은 modeld를 기다리게 하지 않는다.
- C++ modeld가 **유일한 modelV2 발행자**다. 기존 모델 추론과 recurrent state를
  계속 유지한다. 외부 후보를 채택하지 않으면 같은 루프에서 기존 모델을 발행한다.
- `cameraOdometry`는 기존 이온 모델을 유지해 EON의 보정·위치 추정에 사용한다.
- 실제 보정된 영상, 정상 CAN·기존 모델, 올바른 접속·순서·프레임·타임스탬프,
  유한한 전체 출력, 최대 50ms 응답·100ms 결과 나이·한 프레임 차이를 검사한다.
  Python 변환·선택 후 C++에서 메시지와 조건을 다시 검사한다.
- 20개 연속 정상 응답과 인게이지 해제 상태에서 외부를 적용한다. 사용한 응답은
  다시 발행하지 않는다. 늦거나 누락된 응답은 기존 모델로 복귀한다.
- 외부 적용 중 인게이지 상태에서 복귀하면 modeld가 복귀 상태를 잠근다.
  controlsd는 기존 `modeldLagging` 경고/soft disable 경로를 사용한다. 인게이지를
  해제하고 정상 응답을 다시 확보해야 외부로 돌아간다. 자동 재진입하지 않는다.
- 선택 변경은 영속 제어 파일의 새 revision으로 기존 결과를 먼저 무효화한다.
  끊어진 worker가 예전 결과를 나중에 쓰더라도 새 선택에 적용되지 않는다.
- 기존 판다 안전 규칙·차량 제어기를 유지한다. 이 기능이 새 모델의 실차 적합성을
  입증하지는 않는다. 50/100ms·20프레임도 실차 검증이 끝난 기준은 아니다.

기존 핫스팟 시험의 왕복 약 118ms는 50ms 응답 조건을 넘는다. 같은 수치라면 외부
모델이 적용되지 않고 기존 모델을 사용한다. 새 앱이 이 지연을 해결한다고 보장하지 않는다.
지도 렌더러가 없거나 만료되면 N16 지도 입력은 빈 지도를 사용한다.

## 정차 성능 시험

이온웹 **도구 → N16 시험**은 별도의 성능·변환·선택 정책 시험이다. 이 시험 자체는
차량 제어에 적용하지 않는다. 외부 주행 모델을 선택한 동안에는 이 시험을 막고,
P단·정차·인게이지 해제 조건을 유지한다. 실제 카메라 시험 결과는 **최근 결과 저장**과
**변환 출력 저장**에서 받는다. 두 파일 제출은 코드 사용의 선행 조건이 아니다.

## 앱·프로토콜

Android 12+ arm64와 Snapdragon NPU `htp-whole` 경로를 대상으로 한다.
별도 Java UI/foreground service가 CPU·Wi-Fi lock을 유지한다. 화면을 꺼도 서비스가
실행된다. 추가 relay, 전송 압축 선택, 지도 변경 시에만 전송 기능이 있다.

고정 Jetlink Carrot v0.9.0-carrot.46의 JNI 계산 엔진과 ORT/QNN 라이브러리만 재사용한다.
업스트림 APK SHA-256은
`08a083207f58ce574f4ab0bfab13ec81123b7ab782bd24e7f21251e2eb73fd89`이며
소스 revision은 `1133658a61df201ef8b1805fa3e03e493604355b`다.
출처·라이선스는 `NOTICE.txt`, `JETLINK-LICENSE` 및 APK assets에 포함한다.

폰의 5600 EON1 envelope가 localhost 5599의 원본 엔진에 v3 요청을 전달한다.
UDP 5601은 자동 검색이다. 무손실 압축·요청 ID·크기·해시를 검사하고 큐를 쌓지 않는다.
이 프로토콜은 신뢰된 로컬 네트워크용이며 암호화·기기 인증을 제공하지 않는다.

## 빌드·검증

```sh
# JDK17, Android SDK platform35 / build-tools35.0.0
export EONLINK_STORE_PASSWORD=...
export EONLINK_KEY_PASSWORD=...
python tools/eon_link_android/build.py --keystore /path/to/key.p12 --alias your-alias
# C++ publication 통합 시험에는 capnproto, libcapnp-dev, g++ 필요
python -m pytest -q selfdrive/modeld/jetlink/tests
```

CI는 기존 `REMOTE_HUD_*` 서명 secrets와 인증서 지문 검사를 사용하며 versionCode를
증가시킨다. 임시 로컬 시험 키로 서명한 APK는 배포하지 않는다.

호스트 시험은 실제 Java relay 소스, 실제 legacy Cereal 스키마, modeld가 호출하는
동일한 C++ 발행 함수로 외부 발행/기존 복귀/인게이지 중 재진입 차단을 검사한다.
가짜 추론 엔진이나 호스트 통과를 NPU 성능·EON 실행·실차 주행 검증으로 보고하지 않는다.

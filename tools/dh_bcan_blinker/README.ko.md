# 제네시스 DH 자동 깜빡이 (ESP32 + B-CAN)

리모컨·NOO로 오픈파일럿이 차로를 바꿀 때, EON이 Wi-Fi로 ESP32에 요청하면 ESP32가 B-CAN에
**순정 원터치 레버 신호(0x138)** 를 한 번 보냅니다. BCM이 순정 원터치처럼 **외부 램프를 5번** 깜빡입니다.
(2026-11-14 실차 확인: 원터치 1회 = 외부 램프 5회, 경고 없음)

- ESP32 펌웨어: `tools/dh_bcan_blinker/dh_bcan_blinker.ino`
- EON 쪽: `selfdrive/eon_cluster/bcan_blinker.py` (설정 **DH B-CAN BLINKER (ESP32)**)
- 배선도: `tools/dh_bcan_tx_test/final_wiring.png`

## 1. 배선
| 연결 | |
|---|---|
| M01 **1번 녹색** | 보드 CAN **H** |
| M01 **2번 주황** | 보드 CAN **L** |
| 시동 연동 12V (퓨즈 탭, IGN, 2A) | 보드 DC 단자 **VIN** |
| 차체 접지 | 보드 DC 단자 **GND** |

- **보드 CAN 점퍼는 반드시 NC.** (120R이면 B-CAN이 무너져 수신도 안 됩니다)
- 상시 전원(B+)에 연결하지 마세요. 시동을 끄면 보드도 꺼져야 합니다.

## 2. 휴대폰 핫스팟 (S20)
- 설정 → 연결 → 모바일 핫스팟 및 테더링 → 모바일 핫스팟 → ⋮ → 구성 → **대역 2.4GHz**
  (ESP32는 5GHz에 접속하지 못합니다)
- EON도 같은 핫스팟에 접속해 있어야 합니다(지금처럼).

## 3. 펌웨어 올리기
1. `dh_bcan_blinker.ino`를 새 스케치에 붙여넣습니다.
2. 맨 위 두 줄을 고칩니다.
   ```
   #define WIFI_SSID "G80"
   #define WIFI_PASS "핫스팟 비밀번호"
   ```
3. 보드: ESP32S3 Dev Module, USB CDC On Boot: Enabled → 업로드.
4. 시리얼 모니터(115200)에 `Wi-Fi connected: 192.168.x.x, rssi -55 dBm`이 나오면 접속 성공입니다.

## 4. EON 설정
- 설정 → **네비MAP** 탭 → **DH B-CAN BLINKER (ESP32)** 켜기 (재부팅 필요 없음, 2초 안에 적용)
- 리모컨 차로변경을 쓰려면 기존처럼 **BLUETOOTH REMOTE**도 켜져 있어야 합니다.

## 5. 화면 표시 (EON 주행 화면 오른쪽 아래, S9 HUD 리모컨 상자 아래)
| 표시 | 의미 |
|---|---|
| 🟢 깜빡이 연결됨 -55dBm | ESP32 Wi-Fi·B-CAN 모두 정상 |
| 🟡 깜빡이 B-CAN 없음 | Wi-Fi는 되지만 0x138이 안 들어옴 (배선, 점퍼 NC, 시동) |
| ⚪ 깜빡이 연결 안 됨 | 3초 넘게 ESP32 신호 없음 (핫스팟 꺼짐/5GHz, 보드 전원, 비밀번호) |
| 🔴 깜빡이 버스 오류 | 최근 1분 안에 송신 오류 → ESP32가 그 요청을 중단함 |
| 깜빡이 좌 켬 (하늘색 테두리) | 원터치 요청 성공 (3초 표시) |
| 깜빡이 좌 · 레버 사용 중 등 (주황 테두리) | 요청이 거부됨, 이유 표시 |

## 6. 동작 규칙
- 오픈파일럿 조향 중 차로변경이 **준비(preLaneChange) 또는 시작**되면 그 방향으로 1회 요청합니다.
- 차로변경이 4.5초 넘게 계속되면 다시 요청합니다(최대 3회, 약 13초).
- **운전자가 레버로 시작한 차로변경**(이미 같은 쪽 램프가 켜져 있음)에는 보내지 않습니다.
- ESP32는 다음 경우 보내지 않습니다: 레버가 중립이 아님, 최근 0.8초 안에 램프가 켜져 있었음
  (레버·비상등·이전 원터치), 순정 0x138이 0.5초 넘게 안 들어옴, 직전 원터치 끝난 뒤 3.5초 이내,
  버스 오류.

## 7. 처음 확인 순서
1. 주차(P), 시동 ON 상태에서 보드에 노트북을 연결하고 시리얼 모니터에서 `l`, (4초 뒤) `r`
   → 외부 램프 5회씩. `s`로 Wi-Fi·B-CAN 상태 확인.
2. EON 주행 화면과 S9 HUD에 **깜빡이 연결됨**이 뜨는지 확인.
3. 안전한 도로에서 리모컨 차로변경 → 외부 램프 5회, 화면에 **깜빡이 좌/우 켬**.
4. 처음 며칠은 다음 날 아침 시동·스마트키·문 잠금·계기판 경고를 확인하세요.
   이상이 있으면 보드 선을 빼면 원래대로 돌아옵니다.

# 제네시스 DH B-CAN 깜빡이 원터치 송신 테스트

로거로 찾은 레버 메시지(0x138)를 **한 번만 짧게(0.16초)** 보내서, 순정 원터치처럼
**외부 깜빡이가 5번 깜빡이는지** 확인하는 펌웨어입니다.

- 0x138 byte0: `30` 중립, `32` 왼쪽(레버 아래), `31` 오른쪽(레버 위)
- 평소에는 **수신 전용**이고, `l`/`r`을 입력했을 때만 0.16초 동안 송신 모드가 됩니다.
- 순정 0x138을 그대로 복사하고 byte0의 레버 비트(하위 2비트)만 바꿉니다.

## 1. 배선 (반드시 변환기 사용)

**송신은 변환기 없이(방법 3) 절대 하지 마세요.** 보드의 고속 CAN 칩이 저속 B-CAN을 망가뜨릴 수 있습니다.

| 변환기 (M-CAN에서 쓰던 TJA1054) | 연결 |
|---|---|
| 저속 쪽 CANH | M01 **1번 녹색** |
| 저속 쪽 CANL | M01 **2번 주황** |
| 고속 쪽 CANH | 보드 CAN **H** |
| 고속 쪽 CANL | 보드 CAN **L** |
| 9~24V | 차량 12 V (퓨즈 달린 전원) |
| GND | 차체 접지 (M01 6번 또는 차체 볼트) |

- **변환기 저항 점퍼: 기본값 그대로.**
- **보드 CAN 점퍼: 120R 쪽으로** 옮깁니다(로거 때는 NC였음).
- 확인: 전원을 끈 상태에서 보드 H–L 사이 저항이 **약 60 Ω 또는 120 Ω**이면 정상입니다.
  OL(무한대)이면 점퍼를 다시 확인하세요.

## 2. 업로드
1. `tools/dh_bcan_tx_test/dh_bcan_tx_test.ino` 내용을 새 스케치에 붙여넣고 저장합니다.
2. 보드: ESP32S3 Dev Module, USB CDC On Boot: Enabled (로거와 같음).
3. 업로드한 뒤 시리얼 모니터를 **115200**으로 엽니다.

## 3. 테스트 순서
1. **P단, 정차, 시동 ON, 비상등 끔, 레버 중립.**
2. `s` → `stock 0x138: 30 ...` 이 나오고 `ms ago`가 몇백 이하인지 확인합니다.
   - `none yet`이면 변환기 전원, 배선, H/L 뒤바뀜을 확인하세요.
3. `l` → **외부 왼쪽 깜빡이**를 봅니다. 5초 뒤에 결과가 나옵니다.
   ```
   === LEFT tap: waiting for the next stock 0x138 ===
       12345  sent 0x138 32 (copy of stock, lever bits 02)
   === tap end (done): 5 frames sent, tx ok 5, tx fail 0, bus errors 0 ===
   === lamp flashes seen on 0x168: 5 (stock one-touch: 5) ===
   ```
4. 4초 이상 기다린 뒤 `r` → 오른쪽도 같은 방식으로 확인합니다.

## 4. 결과 판단
| 결과 | 의미 |
|---|---|
| 외부 램프 5번 깜빡임, `flashes 5` | **성공.** 다음 단계(리모컨·NOO 연동)로 갑니다 |
| 0~1번 깜빡이거나 안 깜빡임 | 순정 스위치 프레임에 밀렸을 수 있음. 로그 전체를 보내 주세요 |
| `tx fail` 또는 `bus problem ... abort` | 송신 실패. 바로 멈추고 배선·점퍼·변환기 전원을 확인하세요 |
| `refused: ...` | 아무것도 보내지 않은 것. 메시지대로 조건을 맞추세요 |

- 계기판 경고가 뜨거나 다른 이상이 보이면 **바로 선을 뽑으세요.** 시동을 껐다 켜면 원래대로 돌아옵니다.
- 끝나면 변환기를 M-CAN 배선으로 되돌리고, 보드 점퍼도 NC로 돌려 두세요(로거를 방법 3으로 쓸 경우).

결과 로그를 전부 복사해서 보내 주세요.
